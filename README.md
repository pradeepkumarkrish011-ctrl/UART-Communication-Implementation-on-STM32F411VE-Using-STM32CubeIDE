# UART-Communication-Implementation-on-STM32F411VE-Using-STM32CubeIDE
This project demonstrates UART serial communication using the STM32F411VETx (ARM Cortex-M4) microcontroller and STM32CubeIDE. The printf() function is redirected to USART2 using _io_putchar(), enabling formatted text output through UART. The transmitted data is verified using the Tera Term serial terminal.
